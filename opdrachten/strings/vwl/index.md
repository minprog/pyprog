# Vwl

1. Schrijf een functie `remove_vowels` die een string aanneemt en een versie teruggeeft waarin alle klinkers uit de string verwijderd zijn.

2. Als deze gevalideerd is met doctests, voeg dan een `main` toe zodat je het programma kunt runnen, en een woord opgeven dat dan zonder klinkers wordt uitgeprint (met hulp van de functie).

## Algoritme

Tekens direct uit een string verwijderen kan niet, dus het is nodig om een nieuwe string aan te maken en stap-voor-stap te vullen met letters, waarbij je de klinkers weglaat.

Bedenk vooraf:

- wat de input is
- wat een klinker is
- hoe het algoritme er globaal uit moet zien (loops, variabelen)
- wat er teruggegeven wordt en hoe je dat opbouwt (variabele)
- of er nog bijzondere gevallen zijn om rekening mee te houden
