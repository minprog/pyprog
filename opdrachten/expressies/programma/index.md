# Een programma schrijven

In deze opdracht ga je drie Python-programma's schrijven.

## Programma 1

1. Maak een bestand genaamd `prog1.py`.

2. Schrijf enkele regels code in dat bestand:

    - Eerst wordt om invoer gevraagd en opgeslagen in een variabele.
    - Dan wordt die invoer 3x geprint door 3x `print()` te gebruiken.
    - Tip: op pagina 31 van het boek staan twee voorbeelden.

3. Sla op en ga naar de Terminal. Run het programma met `python prog1.py`.

    > We schrijven `python prog1.py` maar welk Python-commando je precies moet geven hangt af van je eigen instellingen. Check eventueel de [installatiepagian(/installatie/pulsar)] voor hints.

4. Je programma zou nu om invoer moeten vragen. Tik iets in. Check of het dan nog 3x datzelfde uitprint.

## Programma 2

1. Maak een bestand genaamd `prog2.py`.

2. Schrijf enkele regels code in dat bestand:

    - Eerst wordt om invoer gevraagd en opgeslagen in een variabele.
    - Dan wordt die variabele 3x geprint door 1x `print()` te gebruiken.
    - Tip: je kunt drie keer `hallo` printen met `print('hallo', 'hallo', 'hallo')`. Je moet hier alleen niet `hallo` printen maar wat er is ingevoerd via het toetsenbord. Vervang dus in het voorbeeld `'hallo'` door de naam van de variable.

3. Sla op en ga naar de Terminal. Run het programma met `uv run prog2.py`.

4. Je programma zou nu om invoer moeten vragen. Tik iets in. Check of het dan op één regel 3x datzelfde uitprint.

## Programma 3

1. Maak een bestand genaamd `prog2.py`.

2. Schrijf enkele regels code in dat bestand:

    - Eerst wordt om invoer gevraagd (een getal!) en opgeslagen als integer in een variabele.
    - Dan wordt de absolute waarde geprint van dat getal.
    - Tip: pas de functie `abs()` toe op het getal: bijvoorbeeld met `print(abs(getal))`.

3. Sla op en ga naar de Terminal. Run het programma met `uv run prog3.py`.

4. Je programma zou nu om invoer moeten vragen. Tik iets in (een negatief getal is wel handig als test). Check of het dan de absolute waarde print.

## Automatisch nakijken

Ga nu naar de tab hierboven "Submit" en stuur je drie programma's in. Je wordt dan doorgestuurd naar de pagina "Voortgang". Als je die na 10-20 seconden ververst, staat er een automatische check klaar die je drie programma's heeft gecontroleerd op de juiste werking.

Begrijp je de output van de check niet (zou best kunnen)? Vraag het de assistenten of je medestudenten.
